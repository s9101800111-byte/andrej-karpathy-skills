# FormworkQTO — Revit 2026 模板面積計算 Add-in

自動計算結構元件（柱／梁／版／牆／基礎）的**側模**與**底模**面積，
扣除混凝土對混凝土的接觸面，寫回共用參數並匯出 CSV 明細。

## 功能

| 指令（增益集 → 外部工具） | 說明 |
|---|---|
| **計算模板面積** | 全模型計算 → 寫回「側模面積」「底模面積」共用參數 → 匯出 CSV 到「我的文件」→ 顯示總量 |
| **模板面積視覺化** | 對「目前選取的元件」建立薄殼 DirectShape：藍色＝側模、紅色＝底模，人工驗證判斷是否正確（Ctrl+Z 復原移除） |

## 演算法

1. **面分類**：取出元件 Solid，依每個面的外法向量 Z 分量分類——
   垂直面→側模；朝下的面（含斜版底面）→底模；朝上的面→不計。
2. **接觸扣除**：對每個模板候選面沿法向外擠出 1.5 cm 薄殼，
   與鄰接混凝土元件（BoundingBox 快篩）的 Solid 取布林**交集**，
   交集體積 ÷ 殼厚 ＝ 接觸面積，予以扣除。
   梁側被版蓋住、梁柱交接、牆版交界等不需模板的部位因此被正確排除，
   且不依賴模型有沒有正確 Join。
3. **統計輸出**：以元件底部高程歸屬樓層，依「樓層 × 類別」彙總，單位 m²。

## 內建計算規則（v1 預設）

- 牆與版只計**「結構」屬性打勾**者（隔間磚牆、裝修面層不計）。
- 版頂、朝上斜面不計模板。
- 基礎的底面貼墊層，不計底模（側面照計）。
- 面上的開口（門窗）已自動從面積中扣除；「小開口不予扣除（回加）」規則尚未實作。
- 元件以**底部高程**歸屬樓層（梁版的支撐架設於下方樓層工作面的慣例）。

## 建置與安裝

需求：Visual Studio 2022（或 .NET 8 SDK）＋ Revit 2026。

```
cd src
dotnet build -c Release
```

API 參考組件由 NuGet 套件 `Nice3point.Revit.Api.*` 提供，**不需要**本機安裝 Revit 才能編譯。
在 Windows 上建置成功後會自動把 `FormworkQTO.dll` 與 `FormworkQTO.addin`
複製到 `%AppData%\Autodesk\Revit\Addins\2026\`，重開 Revit 即可在
「增益集 → 外部工具」看到兩個指令。

## 建議驗證流程

1. 開一個只有**一根獨立柱**的測試檔，執行計算，手算 `周長 × 高` 比對側模面積。
2. 建「柱＋梁＋版」交接組合，選取後執行**視覺化**，確認面分類正確；
   比對數字確認梁側被版蓋住的帶狀區、梁柱交接面有被扣除。
3. 再跑整體模型，抽查 CSV 明細。

## 已知限制（後續版本方向）

- **曲面不做接觸扣除**：圓柱側面面積正確，但與其他元件的接觸不會被扣（圓柱極少側向接合，影響有限）。
- 尚未支援：連結模型、Phase／設計選項過濾、樓梯、小開口回加規則、貼土面規則、Excel 直出（目前為 CSV）。
- 兩個薄殼重疊到同一鄰居的極端情況可能重複扣除，已以「扣除不超過毛面積」封頂。
- 接地層的版底仍計為底模，如為地坪直接澆置請自行於明細中排除。
