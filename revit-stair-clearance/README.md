# 樓梯淨高檢核(Revit 外掛)

Revit 外部命令(`IExternalCommand`):執行後輸入最小淨高要求,自動檢測樓梯上方的物件——
凡垂直投影與樓梯有交集者,量測其最低點到樓梯表面的淨高,低於設定值即列為違規。

## 檢核原理

「找出上方物件 → 向下投影 → 量最低點淨高」這件事,程式裡用等價但更穩健的反向作法:

1. 取出樓梯(梯段 + 平台)幾何中所有**朝上的表面**(法向量 Z > 0.7)。
2. 在這些表面上以固定間距(預設 300 mm)佈設檢測點網格。
3. 從每個檢測點**垂直向上發射射線**(`ReferenceIntersector`),
   命中的第一個元件就是「垂直投影與樓梯相交的上方物件」,命中距離就是該點淨高。
4. 任何一點淨高低於輸入值,即記錄一筆違規(每個障礙物只保留最差的一筆)。

射線會自動排除樓梯自身的梯段、平台、支撐與其扶手,避免打到自己造成誤判。
上一跑梯段、樓版開口邊緣、樑、風管、水管、天花板等任何有實體面的元件都會被偵測到。

## 使用方式

1. (可選)先選取要檢核的樓梯;不選則檢核全模型所有樓梯。
2. 執行「外部工具 → 樓梯淨高檢核」。
3. 輸入**最小淨高要求**(mm,預設 1900)與**檢測點間距**(mm,預設 300),按「開始檢核」。
4. 結果對話框列出每筆違規:樓梯、障礙物、實測最小淨高、平面位置;
   違規障礙物會自動加入選取集,方便直接定位。

檢測點間距越小越精準但越慢;300 mm 對一般檢討已足夠(每階踏面至少有一排檢測點)。

## 編譯

需要 .NET SDK(或 Visual Studio)。Revit API 參考使用 NuGet 套件
`Nice3point.Revit.Api.*`,不用裝 Revit 也能編譯:

```
cd src
dotnet build -c Release                    # 預設對應 Revit 2024
dotnet build -c Release -p:RevitVersion=2022   # 其他版本(支援 2021~2024)
```

> Revit 2025 以後改用 .NET 8,需將 `TargetFramework` 改為 `net8.0-windows`。

## 安裝

把編譯出的 `StairClearanceCheck.dll` 和本資料夾的 `StairClearanceCheck.addin`
一起複製到:

```
%AppData%\Autodesk\Revit\Addins\2024\
```

重新啟動 Revit,指令會出現在「增益集 → 外部工具」。

## 已知限制

- 不檢核連結模型中的物件(可將 `ReferenceIntersector.FindReferencesInRevitLinks`
  設為 `true` 擴充)。
- 「多層樓梯」若是單一元件(同一 Stairs 元件複製到多層),上層梯段屬同一元件
  會被一併排除;一般每層獨立建模的樓梯不受影響。
- 在 3D 視圖中被隱藏的元件不會被射線偵測;程式會優先選用未啟用剖面框的 3D 視圖,
  若模型沒有任何 3D 視圖會自動建立暫存視圖、用完即刪。
